Built-in maps, all equirectangular (lat-long, 2:1, north at the top).

| file | slot | source |
| --- | --- | --- |
| `earth-day.jpg` | day / albedo | NASA Visible Earth — Blue Marble Next Generation (public domain) |
| `earth-night.jpg` | night lights | NASA Earth at Night / Black Marble (public domain) |
| `earth-water.jpg` | water mask | NASA-derived land/water mask, via the three.js example textures |
| `earth-normal.jpg` | normal map | NASA-derived topographic normals, via the three.js example textures |
| `checker.png` | day / albedo | generated by `scripts/make-checker.mjs` |

To swap a default, drop a replacement in with the same filename. To try one
without touching the repo, use the file picker next to the slot in the sidebar.

`scripts/fetch-earth-textures.sh` re-downloads and re-crops the earth maps
(2048x1024 by default; raise `RES_W`/`RES_H` in the script for more detail).

Note `earth-normal.jpg` is Y-down (green = south), which is why "flip normal
green" defaults to on. If your own normal map looks lit from the wrong side
north-to-south, toggle it off.
